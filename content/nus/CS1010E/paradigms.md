

Computer programs can be written:

1. declaratively - expresses what to do (high level)
2. imperatively - describes how to do something (low level)

Python is a multi-paradigm language, so it can be written using the traditional imperative way that focuses on manipulation of program state or a more declarative pythonic way that is stateless and focuses on the use of higher order abstractions.
