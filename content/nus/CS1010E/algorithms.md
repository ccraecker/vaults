attributed to Persian scholar al-Khwarizmi

a well-defined computational procedure that
- takes some value as input
- and produces a value (or a set of values) as output

think of function machines

An algorithm must have/be:
- Exactness: each step must be deterministic
- Effective:
    - the first aspect of effectiveness is correctness.  Given some input, the algorithm must give the correct expected output. 
    - the second aspect is efficiency.  It is desirable that the algorithm produces the output quickly, with minimal resources.
- Generality: given any possible input, the algorithm must produce the corresponding expected output.
- Termination: the algorithm must end, and not run forever.
